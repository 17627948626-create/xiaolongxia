## DOM 安全根因分析摘要（供后续参考）

- 微信后台把 10+ 个弹窗全部预渲染进 DOM，靠 CSS 控制显隐（display:none / visibility / opacity）
- 其中包含"账号切换 / 退出登录"弹窗，按钮就在 hidden 状态的 .weui-desktop-dialog 里
- 子 Agent 未加可见性过滤直接全局 querySelector，命中了隐藏弹窗里的"退出登录"按钮
- offsetParent !== null 不足以过滤：WeUI modal 是 position:fixed，此时 offsetParent 恒为 null，正确可见弹窗也会被过滤掉
- 正确方案：getBoundingClientRect().height > 0 + getComputedStyle 组合判断，再结合弹窗关键词精确匹配
- 此问题在每次跑发表流程时都有概率触发，不是偶发，已于本次复盘中系统修复
