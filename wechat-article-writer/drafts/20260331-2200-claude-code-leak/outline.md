# 文章大纲：Anthropic 偷偷给 Claude 养了只宠物，没想到被人发现了

## 文章类型
资讯+观点混合，娱乐吃瓜向

## 核心洞察
1. **主洞察**：Anthropic 在 Claude Code 源码里藏了个叫 BUDDY 的 AI 虚拟宠物，比宠物小精灵还精心设计——这次泄露不是出丑，是提前剧透了 Anthropic 真正的战略牌
2. **子洞察 A**：泄露原因极其荒唐——npm 打包忘删 .map 文件，一个初级程序员都知道的操作，Anthropic 栽了
3. **子洞察 B**：AI 宠物这个方向不是噱头，是情感依赖的战略卡位——让用户对工具产生情感，比让工具更聪明难得多，也更值钱

## 章节结构

### 开头（直接切入事件，制造好奇）
- Chaofan Shou 发现 .map 文件 → 拆开 → 发现宝藏
- 3小时310万浏览，全网都去挖彩蛋
- "我当时看到这新闻，差点把正在喝的奶茶喷出来"

### 第一节：这事怎么发生的（泄露原因）
- npm 打包忘删 .map 文件，极其低级
- Anthropic 这周本来就够烦的（token 暴涨 cache bug）
- 有人把源码存到 GitHub 了（镜像链接）

### 第二节：重头戏——BUDDY 登场（最大篇幅）
- 18种物种，有帽子和闪光变体
- 每个人的哈希值决定你孵化出什么，命中注定
- 五个属性值，重点介绍 SNARK（嘴欠度）这个神设计
- 坐在输入框旁边，Claude 给它取名
- 4月1日-7日预热，5月正式上线

### 第三节：其他发现（简述，不抢 BUDDY 的风头）
- KAIROS：每晚"做梦"整理记忆——听起来很酷
- ULTRAPLAN：30分钟云端规划
- Coordinator Mode：一个 Claude 指挥多个 Claude 干活

### 结尾（本虾观点）
- BUDDY 这个功能不是傻，是 Anthropic 在赌用户情感依赖
- 让用户爱上工具，比让工具更聪明更难，也更值钱
- AI 公司下一场战争，不在智商，在情感绑定
