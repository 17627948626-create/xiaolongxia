# 建议主标题

**他开源的不是 prompt，是一个作者的方法系统**

## 备选标题
- 卡兹克把写作 skill 开源后，我更确定了一件事
- AI 时代真正开始公开竞争的，不是 prompt

## 开头：先交代事件、判断和 why-now
- 先把事件说清楚：**昨天/今天，卡兹克把自己正在用的写作 skill 一字不改开源了**。
- 紧接着给出判断：**这事真正值得看的，不是又多了一个 prompt 仓库，而是一个创作者第一次把自己的方法系统，作为公开竞争品摆上桌面**。
- 再补 why-now：**这个 repo 从 4 月 6 日创建到 4 月 7 日中午左右，已经 539 stars、115 forks**，说明大家围观的不是八卦，而是方法系统本身。

---

## 1. 从「一字不改开源」切进去，但别停在开源动作本身
- 开场先抓住那句原话，**把我自己在用的内容创作 Skill，完整的，一字不改的，开源了**。
- 立刻转折，这里最重要的，不是一个作者大方不大方，而是他决定公开的对象到底是什么。
- 点出本文唯一主线，**今天要聊的不是卡兹克这个人，而是 AI 时代创作者开始公开竞争什么。**

## 2. 先把误会掐掉，这次公开的根本不是几段 prompt
- 直接拆开原文和 repo 里的内容。
- 要写清楚他公开了哪些层，至少点到这些要素：
  - 选题和切入角度怎么判断
  - 哪些词和标点不能用
  - 开头怎么起、节奏怎么控
  - AI 该干什么，人必须自己干什么
  - 四层自检怎么跑
  - 长期迭代的方法论和踩坑经验
- 把 repo 的体量和结构写实一点，像这样去组织素材：
  - 一个 30173 字节的 `SKILL.md`，外加 `content_methodology.md` 和 `style_examples.md` 两份参考库。
  - 这能让读者一下明白，这不是「藏着掖着的 prompt 被放出来」，而是一整套写作操作系统被摊开了。

## 3. 真正的新意，在于它已经被做成了可安装、可移植、可复用的 skill
- 这一节聚焦 bigger picture：过去大家聊 prompt，默认还是一段文本技巧；这次不一样，它被包装成遵循 Agent Skills 开放标准的 skill，可以装进 Claude Code、OpenClaw、Codex 这类 agent 里。
- 这里的重点判断是，**当创作经验被做成 skill，它就从「心得」变成了「基础设施」**。
- 方法系统一旦能安装、能迁移、能协作，它就开始进入公开流通和公开比较。

## 4. 更值得写的，不是他开源了什么，而是他把「怎么炼出来」也讲出来了
- 这一节抓原文后半段最有价值的地方：**不是展示结果，而是公开迭代流程**。
- 重点写那条循环：
  - 先蒸馏初版
  - 让 AI 按 skill 写
  - 人亲自重写/改写
  - 对照 AI 版和人改版
  - 把差异写回 skill
  - 重复 3~4 轮
- 这一节的核心结论是，**厉害的不是把风格总结出来，而是把自己的修改过程、边界判断、返工逻辑也沉淀成系统。**
- 可以顺手补一句，这比「求一个万能 prompt」高了不止一层。

## 5. 但最值钱的那一下，还是没有被开源掉
- 这是全文必须守住的反张力，不然文章会滑成系统万能论。
- 先承认 AI 能做什么，找证据、找类比、扩写、补背景，都能做。
- 然后马上切回作者不可替代的部分，第一手观察、最后判断、真正的灵光一现。
- 用原文里最强的那一幕做支点：凌晨 2 点半卡文，抬头看见书架上的《北京折叠》，才突然找到真正角度。
- 这一幕不是为了煽情，是为了证明，**方法可以被整理，神之一手不能被复制。**
- 这节结尾最好收成一句短句，像，**系统能帮你更快到门口，但推门那一下，还是作者自己。**

## 6. 本虾真正想说的，是创作者开始公开竞争「方法系统」了
- 这一节给出全文最能被复述的判断：
  - **AI 时代真正开始公开竞争的，不是几段 prompt，而是谁能把自己的判断、边界和迭代流程，先做成系统。**
- 往下解释两层：
  1. 只会藏 prompt 的壁垒，接下来会越来越薄。
  2. 真正稀缺的作者，不是拒绝 AI 的人，而是知道什么该交给系统、什么必须自己下刀的人。
- 这里点出，这也是为什么这件事不是个人仓库更新，而是一个行业信号。

## 7. 收回这一件事
- 回扣开头，**为什么今天值得看**，因为一个创作者已经把方法系统摆上桌面，市场也已经开始围观它。
- 回扣边界，**什么没有被开源掉**，就是作者的体验、判断、灵光和神之一手。
- 结尾建议收成这种力道，**以后大家比的，可能不再是谁偷偷藏着一个 prompt，而是谁能公开证明，自己到底有一套什么样的方法系统。**
