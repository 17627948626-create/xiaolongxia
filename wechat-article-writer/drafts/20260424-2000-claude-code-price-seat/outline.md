# Anthropic 差点把 Claude Code 从 20 美元套餐里拿掉，说明最先涨价的不是模型，是工位

## 1. 先把这次风波讲清楚：大家为什么一下就炸了
4月22日前后，外部媒体注意到 Anthropic 的公开页面一度出现 Pro 套餐不再包含 Claude Code 的迹象。用户之所以反应这么大，不是因为少了一个边角功能，而是因为很多人已经把 Claude Code 当成真实生产工具在用。一个 20 美元套餐里的小改动，瞬间就像在告诉大家：这张桌子可能要单独收费了。

## 2. 这不是单纯的页面事故，Anthropic 自己也承认在试
Anthropic 增长负责人随后解释，这是面向约 2% 新 prosumer 注册用户的小范围测试。更关键的是他给出的理由：当初 Max 设计出来时，Claude Code 还没被打包进去，Cowork 也不存在，能跑好几个小时的 agent 还不是日常工作流。现在情况变了，长时异步 agent 已经成了 everyday workflows，用户对订阅的使用方式也变了。

## 3. 真正值得写的，不是它拿没拿掉，而是它为什么会想拿
如果一个工具只是偶尔聊两句、写一小段代码，20 美元套餐还能靠平均值兜住。但 Claude Code 现在的定位已经不是聊天框里的附属插件。官方文档写得很直白：它会读代码库、编辑文件、运行命令；网页版还能发起长时任务，做完再回来收结果，还能并行跑多个任务。到了这个阶段，成本就不再只是一问一答的 token，而是持续在线、持续执行、持续占资源。

## 4. Anthropic 的官方页面，其实已经把这套新成本语言写出来了
4月24日重新核验时，Anthropic 当前 pricing 页面和 Claude Code 产品页都恢复成了 Pro 包含 Claude Code。但同一套官方页面里，另一个更重要的信号也摆在那儿：Max 写的是比 Pro 多 5 倍或 20 倍 usage；平台侧还单独列出 Managed Agents 的 session-hour active runtime 计费，以及 Code execution 的每小时每容器计费。这个语言体系本身就在变，它越来越像在卖运行时、卖占用时长、卖执行席位。

## 5. 所以这次让人发毛的地方，是 AI 编程开始长出“工位价”了
过去大家谈 AI 成本，第一反应是模型贵不贵、token 贵不贵。现在更难算的账变成了：这个 agent 会不会挂着跑一小时、两小时，是否要并行占多个任务位，是否要持续调用工具、容器、上下文和调度资源。用户嘴上买的是 Claude Code，厂商心里算的已经越来越像一个数字工位。

## 6. 为什么偏偏是 Claude Code 这种产品最先把矛盾捅出来
因为它最接近“替你干完整段工作”的状态。写代码这件事天然适合被拆成长链路：读仓库、改文件、跑命令、修测试、再继续追结果。只要用户真的开始把它当助手以外的执行者，订阅模式就会被压得很难看。一个本来为聊天设计的套餐，突然被拿来养长时 agent，早晚会出边界测试。

## 7. 这次恢复不代表问题消失，只代表 Anthropic 还在摸价格带
现在官方页面又写回 Pro 包含 Claude Code，说明这轮测试暂时没有直接落成公开规则。但这次风波已经把方向暴露出来了：接下来 AI 公司最先重新定价的，很可能不是单次模型访问权，而是那种能长期在线、持续接活、并行执行的席位型能力。今天是 Claude Code，明天可能就是更多 agent 产品都会碰到的同一道题。

## 8. 这篇文章最后该落的一句判断
Anthropic 差点拿掉的表面上是 Claude Code，真正被掀开的却是 AI 编程的定价底牌：模型只是脑子，真正开始涨价的，往往是那个替你一直坐在工位上干活的东西。
